Un carrito de compra con STOCK en un solo archivo HTML. OBLIGATORIO: 3 productos como <div class="prod"> con data-id p1,p2,p3, data-precio 100,50,25 y data-stock 2,3,1. Cada uno tiene un <button class="add" data-id="pX">. El carrito muestra sus lineas como <div class="linea"> con data-id, cada una con <span class="cant"> y un <button class="quitar" data-id="pX">. <span id="total"> tiene el total. REGLAS: anadir el mismo producto NO crea una linea nueva, incrementa su cantidad. NO se puede superar el stock: al llegar al tope, el boton add de ESE producto queda disabled. Al quitar una unidad, si la cantidad llega a 0 la linea DESAPARECE y el boton add vuelve a habilitarse. El total se recalcula siempre.
